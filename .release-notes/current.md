## 修改点

- 课程公式统一使用标准 LaTeX 数学语法，新增 `SchoolFormula` 原生 Compose 渲染层；课程数据不再绑定具体第三方渲染器。
- Lesson 教材引用收口到顶部右侧唯一 `PDF` 入口，正文不再插入教材跳转步骤；入口直接定位到当前 Lesson 的教材参考页。
- 七上课程正文按教材原有知识顺序、术语和讲解节奏重新校正表达，保留教材式的引入与归纳风格，同时继续使用原创措辞和原创例题练习。
- 新增统一 UI 控制层，集中管理页面间距、标题、分割线、设置行、顶部栏和可滚动 Tab，设置页与课程页不再各自复制布局常量。
- 统一 Material Typography 层级，用户的 90% / 100% / 115% / 130% / 150% 文字缩放仍由 SchoolTheme 一次应用，页面组件只负责自适应布局。
- authored Lesson 改为稳定的语义翻页：学习目标、教学阶段、总结与练习按教学含义分页，每页内部内容过长时仍可纵向滚动。
- 课程练习固定排在教学内容和总结之后，一题一页；答案与解析默认收起，由学习者主动查看。
- 精简 JVM 测试套件，删除依赖源码字符串、具体 Compose 实现、固定 UI 文案和已退役课程分析模型的低价值测试；保留课程契约、数学与科学计算、判题、下载更新、安全校验等真实行为测试。
- 统一检查学科、今天、路径、题库、复习、验证、设置、教材 PDF 与更新弹窗的大字号布局，左右信息统一按“主内容占剩余宽度、短状态保持单行、组件允许自然增高”的规则处理。

## 修复点

- 修复分数、根式、上下标、角度和方程等公式只能以普通文本显示的问题；长公式不再通过压缩文字适配窄屏。
- 清理七上课程中 64 个正文 `sourceLink` 和非公式型“流程公式”，20 个真正公式全部改为纯 LaTeX 表达式。
- 修复路径页掌握度趋势在放大文字后右侧百分比被压成竖排、说明文字被挤成异常换行的问题；标题与数值现在按剩余空间布局，百分比禁止换行，说明文字独占完整宽度。
- 修复趋势图纵轴标签在大字号下可用宽度过窄的问题，扩大标签区域并禁止百分比标签换行。
- 修复学科与教材选择页使用固定高度按钮、左右标题与安装状态互相挤压的问题；按钮改为最小高度并允许随文字自然增高。
- 修复题库模式列表、知识掌握状态、作答输入框和底部操作在 130% / 150% 字号下容易拥挤或截断的问题。
- 修复复习列表、验证页、课程资源设置、PDF 翻页按钮、更新弹窗和主底部导航中的短状态文字被压缩换行的问题。
- 修复 Lesson 把完整课程、总结和练习全部塞进一个长滚动页，导致标题重复、信息密度过高和课程节奏不清的问题。
- 修复超长 Lesson 标题在顶部栏占用过多空间的问题，统一为单行省略显示，不再在正文重复巨型标题。
- 修复课程 JSON 的可选 hint/title/note 为 null 时被解析成字符串“null”的问题，截图中的“提示：null”不再出现。
- 修复设置页在放大文字后 Tab 被压缩、AI 标签出现竖排错位的问题；Tab 空间不足时改为横向滚动且禁止换行。
- 修复设置输入框和设置行使用固定高度导致 130% / 150% 字号下文字拥挤、基线错位的问题，统一改为最小高度自适应布局。
- 保留语义分页与 JSON null 等行为回归测试，不再用源码文本断言锁死 UI 实现方式，减少正常重构造成的误报。
