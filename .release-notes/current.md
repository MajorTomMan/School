## 修改点

- 课程按小节组织讲解与节末题组；每个小节讲解完成后立即进入一题一页答题页。
- 答题页增加 AI 判题与解释按钮，并常驻答案、反馈和参考解析输出区域；课程标准答案仍由本地确定性规则判定。
- 人工重做七年级上册 1.2.3 相反数，新增等距镜像、−a 和双重负号交互及 5 道逐题练习。
- 数轴可视化改用 dp/sp 密度换算，扩大刻度、点位、标签和结论文字。
- 应用版本提升至 0.24.0。

- 为七年级上册 1.1、1.2.1、1.2.2 新增三套逐题题组，共 15 道人工编写并确定性判题的样板题。
- 新增 9 个知识点及前置关系，覆盖相反意义的量、正负数与0、有理数分类、数轴要素、点位和移动。
- 样板题覆盖整数、小数、等值分数、单选和位置对五种输入，并使用文字、公式、结构化表格、教材裁剪图和 APK 原生数轴场景。
- 人工核对教材第 9 页相对位置图，按批准坐标从原 PDF 生成高清 PNG，保留原方向、距离和标注。
- 新增课程答题扩展准备与严格校验工具，检查题组位置、知识点依赖、答案规则、图片引用和真实尺寸。
- 课程标准化、ZIP 构建和 R2 清单现已携带可选的 assessments.json、knowledge-points.json 与 assets 文件。
- 添加 APK 原生契约测试和发布工具测试，确保正式样板数据能被当前 App 严格解析。
- 设置页新增课程管理入口，可主动检查 stable 课程更新、查看逐册更新类型、文件数量和预计下载体积。
- 新增本地课程缓存统计与安全清理；默认只删除课程包、教材 PDF、图片、分片和暂存目录，不删除答题记录、复习计划或掌握度。
- 课程下载现在由唯一 WorkManager 任务持有，Activity/Compose 因 onPause、onStop 或配置变化重建后会重新绑定原任务。
- 完整包和外部课程文件支持保留 `.part` 并通过 HTTP Range 断点续传，进程被系统回收后可继续已有下载。
- 课程阅读页新增环节进度条、长内容滚动提示和更明确的翻页操作，完整教学环节仍在单页内纵向阅读。
- 有理数关系图改为原生 Compose 等值变换动画，点选整数、小数和循环小数时直接展示它与分数形式的相等关系。
- 应用版本提升至 0.23.0，内部版本基线提升至 27。
- 新增 `version.properties` 作为 Gradle 与发布流水线共用的唯一版本来源。
- 新增版本策略 CI；以后修改 APK、构建配置或发布流程时，必须同时递增版本名称和版本代码。

## 修复点

- 修复长页滚动提示悬浮遮挡正文、滑块和可视化说明的问题。
- 修复正文静态练习挤在同一页、没有输入区和提交按钮的问题。
- 移除题组中的教材裁剪图片，改用 APK 原生数轴场景。

- 完整课程 ZIP 不再只包含 course.json；存在答题扩展时会按稳定顺序打包全部业务文件和已批准素材。
- 增量更新清单会逐文件声明答题数据和图片，使后续只下载发生变化的内容。
- 未同时出现的答题/知识点文件、未使用图片、错误知识点关系和未批准裁剪会在发布前失败。
- 修复界面切到后台或重建时下载状态丢失、重复排队以及任务可能从头开始的问题。
- 修复协程取消被当作普通下载失败吞掉的问题，系统停止 Worker 时由 WorkManager 正确恢复同一任务。
- 下载进行中禁止清理课程缓存，避免 active、staging 与分片目录在安装过程中被移走。
- 修复 Gradle 默认版本与 GitHub Actions 发布版本分别写死、可能互相不一致的问题。
