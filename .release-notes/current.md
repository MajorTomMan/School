## 修改点

- “验证”保持学科入口页结构，数学、物理、化学、生物、英语、日语为同级入口；点击学科后以横向翻页动画进入独立学科页面，返回时反向翻回。
- 新增跨学科 `Verification Core`，统一 `SubjectEngine`、题型、强类型 Artifact、结构化 `VerificationStep`、警告和语义化可视化请求；公共层只统一协议，不提供万能求解器。
- Verification Core 预留 `DETERMINISTIC`、`CONTEXTUAL`、`EVIDENCE_BASED` 三种验证模式；当前数学使用完全确定的本地模式。
- 数学页改用 `MathVerificationEngine`，直接复用 `BigRational`、`ScienceExpression`、`Polynomial`、`AlgebraSolver` 等本地数学内核，支持数值表达式、精确分数、单变量多项式、一元一次方程、一元二次方程和可识别函数图像。
- 数学求解结果使用结构化逐步解析，每一步包含稳定规则 key、变换前后表达式、解释和必要条件；函数图继续复用隔离的 `mathematics.function.graph` 可视化能力。
- 数学输入支持常用符号归一化，包括 `×`、`÷`、中文括号、`π`、简单 `√`、隐式 `2x`，以及 `y=...` / `f(x)=...` 写法。
- 教材目录解析改为严格的当前 `book + lessons` 契约，内置教材目录同步迁移；删除旧章节嵌套目录和 `bookId` 回退解析，不再维护两套教材目录格式。
- 课程领域和持久化字段统一使用当前 `grade`、`lessonId`、`textbookKey` 命名；Room 数据库升级到 v4，通过一次性 3→4 迁移搬运已有数据，运行时不保留旧字段或双 API。
- 清理旧验证与实验室架构：删除通用 AI 验证协议、旧方程验证器、旧实验室入口/模型、旧 Generated/Minimal 学习页面、旧学科实验样板和 Scene 预览页面，不保留兼容转发层。
- 清理旧课程工具测试和历史交互课程文档，只保留当前仍有实现和发布价值的契约、领域测试与架构说明；历史 `V2`、`Compat`、`Alias` 文件名也统一收正。
- CI/CD 删除重复发布说明工作流和“退役代码不得返回”的墓碑检查；Android 构建与 dev 发布拆成独立 Job，PR 只使用只读仓库权限。
- GitHub Actions 更新到当前主版本：Checkout v7、Setup Java v5、Setup Python v7、Setup Android v4、Gradle Actions v6、Artifact Upload v7，并在 dev 发布阶段独立下载构建产物。
- 物理、化学、生物保留现有确定性领域内核和学科入口，后续适配到同一 Verification Core；不为了旧 UI 保留重复实现。

## 修复点

- 修正上一版数学验证只能处理数值表达式和函数、无法处理方程和逐步答案的问题；现在可本地求解一元一次和一元二次方程并输出可复核步骤。
- 修正验证能力散落在页面和旧专项工具中的问题；新页面只调用 Math Engine，UI 负责输入与展示，数学规则留在领域层。
- 删除已经失去入口但仍参与编译和测试的旧代码，避免后续修改同时维护新旧两套课程/验证流程。
- 删除针对已经退役实现的兼容测试和 Python 工作流测试，测试范围重新聚焦当前课程契约、数学验证、可视化隔离和仍在使用的领域能力。
- 修正教材包示例仍使用旧章节目录格式的问题，并增加当前扁平教材目录契约测试。
- 明确数学能力边界为初高中知识：极限、导数、微分、积分等高等数学内容返回 `UNSUPPORTED`，不会回退网络或 AI。
- 数学输入无效、多变量或超出当前求解范围时返回结构化能力边界，不猜测结果。
