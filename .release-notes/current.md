## 修改点

- “验证”保持学科入口页结构，数学、物理、化学、生物、英语、日语为同级入口；点击学科后以横向翻页动画进入独立学科页面，返回时反向翻回。
- 新增跨学科 `Verification Core`，统一 `SubjectEngine`、题型、强类型 Artifact、结构化 `VerificationStep`、警告和语义化可视化请求；公共层只统一协议，不提供万能求解器。
- Verification Core 预留 `DETERMINISTIC`、`CONTEXTUAL`、`EVIDENCE_BASED` 三种验证模式；当前数学使用完全确定的本地模式。
- 数学页从简单表达式计算器升级为 `MathVerificationEngine`，直接复用已有 `BigRational`、`ScienceExpression`、`Polynomial`、`AlgebraSolver` 等本地科学数学内核，不再在 UI 内重复维护求解逻辑。
- 数学当前支持数值表达式、精确分数运算、单变量多项式展开与合并、一元一次方程、一元二次方程，以及可识别的函数图像。
- 数学求解结果新增结构化逐步解析：每一步包含稳定规则 key、变换前后表达式、解释和必要条件，可直接展示和单元测试，而不是预先拼好的字符串列表。
- 函数验证继续复用可视化基础设施中的 `mathematics.function.graph`；Math Engine 只返回 renderer、语义参数和文本，不接触 Canvas、布局或采样实现。
- 数学输入继续支持常用符号归一化，包括 `×`、`÷`、中文括号、`π`、简单 `√`、隐式 `2x`，以及 `y=...` / `f(x)=...` 写法。
- 删除被新 Math Engine 取代的 `LocalMathExpressionVerifier` 及其旧测试，不保留两套本地数学验证逻辑。
- 物理、化学、生物暂保留学科入口；后续将现有确定性领域内核适配到同一 Verification Core，而不是重新实现算法。英语、日语和语文框架暂不在本阶段接入。

## 修复点

- 修正上一版数学验证只能处理数值表达式和函数、无法处理方程和逐步答案的问题；现在可本地求解一元一次和一元二次方程并输出可复核步骤。
- 修正验证能力散落在页面和旧专项工具中的问题；新页面只调用 Math Engine，UI 负责输入与展示，数学规则留在领域层。
- 明确数学能力边界为初高中知识：极限、导数、微分、积分等高等数学内容返回 `UNSUPPORTED`，不会回退网络或 AI。
- 数学输入无效、多变量或超出当前求解范围时返回结构化能力边界，不猜测结果。
