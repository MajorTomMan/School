# 答题、判题与掌握度架构实施计划

## 目标

把教材中的例题与练习升级为可独立作答、可跳过、可恢复、可统一结算的题组，并将首次正确、错误提交次数、提示使用、最终结果等事实转换为可追溯的掌握度证据。

## 架构原则

1. 课程定义不可变，用户状态独立保存。
2. 每次提交保存为事实记录，统计结果由事实派生。
3. 判题模块只负责规范化与判定，不直接修改进度或掌握度。
4. 掌握度模块只消费证据，不读取 Compose 状态。
5. UI 只发送意图并渲染状态，不承载领域规则。
6. 课程包只携带声明式数据，不允许任意脚本或可执行判题逻辑。
7. 同一题目通过 `questionId + revision` 保持历史记录可解释。
8. 完成题组与更新掌握度必须在一个数据库事务内完成。

## 分阶段计划

### 阶段 1：领域基础与纯函数测试

- [ ] 建立题组、题目、答案输入与答案规则模型。
- [ ] 建立提交记录、跳过记录、单题状态与题组汇总模型。
- [ ] 区分输入无效、答错、部分正确和答对。
- [ ] 统计首次正确率、最终正确率、完成率、做错题数、错误提交总次数、错后改对和跳过数量。
- [ ] 建立掌握度证据和可版本化的更新策略接口。
- [ ] 添加纯 JVM 单元测试。

完成标准：不依赖 Android UI、Room 或课程 JSON，所有领域规则由单元测试覆盖。

### 阶段 2：课程包严格契约

- [ ] 将课程包拆分为 `course.json`、`assessments.json`、`knowledge-points.json` 和资产文件。
- [ ] 新增严格解析器和未知字段拒绝策略。
- [ ] 支持整数、小数、分数、单选和坐标题。
- [ ] 支持文字、公式、图片、表格和 APK 原生场景作为题干。
- [ ] 给课程构建工具增加契约校验与测试。

完成标准：旧 APK 拒绝新契约，新 APK 能严格解析且不静默降级。

### 阶段 3：Room 持久化与事务结算

- [ ] 建立 assessment session、attempt、learning event、mastery state、evidence 和 snapshot 表。
- [ ] 建立 DAO、Repository 与 schema migration。
- [ ] 实现中断恢复和同一 session 幂等结算。
- [ ] 把错误提交、提示查看、解析查看和跳过保存为事实事件。

完成标准：进程被杀后可继续；同一题组不会重复更新掌握度。

### 阶段 4：应用用例与状态机

- [ ] 实现开始、提交、跳过、返回、补答和完成题组用例。
- [ ] 建立 AssessmentSessionController 与明确 UiState/Intent。
- [ ] 完成最后一题时检查未作答题，并允许补答或直接结算。
- [ ] 答对后锁定本次结果，重新练习创建新 session。

完成标准：应用层无需 Compose 即可通过状态机测试完整流程。

### 阶段 5：逐题 Compose 页面与结果页

- [ ] 每道题独立一页，题干区域可纵向滚动。
- [ ] 提供上一题、跳过、提交、提示、解析和下一题操作。
- [ ] 显示当前题错误次数与尝试次数，但避免惩罚性视觉表达。
- [ ] 结果页展示首次/最终正确率、完成率、做错题数、错误提交次数、错后改对、跳过和提示使用。
- [ ] 支持查看错题、补做跳过题和重新练习。

完成标准：旋转、返回前台和进程恢复后状态一致。

### 阶段 6：图片、表格与教材图处理

- [ ] 简单数学图使用原生 scene 重建。
- [ ] 简单表格结构化渲染，并保留教材原表入口。
- [ ] 复杂图表从 PDF 裁剪为受校验的本地资产。
- [ ] 增加图表候选识别与人工复核报告。
- [ ] 校验图片格式、尺寸、路径、摘要和像素上限。

完成标准：没有因 OCR 或自动重建导致的教材信息丢失。

### 阶段 7：七上样板课程

- [ ] 人工校正七年级上册 1.1 至 1.2.2。
- [ ] 覆盖整数、分数、单选、坐标/数轴题。
- [ ] 覆盖原生图、结构化表格和教材截图。
- [ ] 发布到 R2 testing，完成实机验收。
- [ ] 验证掌握度曲线节点可以解释分数变化。

完成标准：内容、交互、统计、恢复和掌握度全部通过人工验收。

### 阶段 8：六册推广与质量门禁

- [ ] 批量转换六册课程并生成待复核清单。
- [ ] 增加题目 ID、知识点覆盖和资产完整性审计。
- [ ] 增加课程包回归测试和截图测试。
- [ ] 保持 testing → 人工验收 → stable 的发布流程。

完成标准：六册全部使用新契约，并可安全回滚到任一历史 release。

## 第一版明确不做

- 复杂代数 CAS。
- 手写识别。
- 主观题 AI 判分。
- 动态生成题目。
- 多账户和云端答题同步。

这些能力应通过现有接口扩展，而不是进入第一版核心路径。
