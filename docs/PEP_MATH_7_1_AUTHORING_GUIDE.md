# 人教版数学七年级上册课程编写基线

本文件是 `pep-math-7-1` 新课程包的内容精校基线。旧的“按教材页自动拆成数百个课程页面”的方案已经退役，不再维护兼容层，也不再使用 `教材第 X 页（N）` 之类的临时页面标题。

## 权威来源

- 教材：义务教育教科书·数学七年级上册，人民教育出版社，2024。
- 教材 PDF：202 页。
- 教材印刷页：1～195 页。
- `textbook.pdf.pageIndexOffset = 7`，即印刷第 1 页对应 PDF 第 8 页。
- authored course 唯一源文件：`courses/pep-math-7-1/course.json`。

课程正文重新编写，不长段复制教材原文；教材负责确定编排、概念边界、术语、例题类型、栏目位置和教学语气，App 负责把这些内容组织成更适合交互学习的步骤、练习与可视化。

## 编排原则

课程顺序严格跟随教材，不另造一套知识顺序：

1. 章引言；
2. 正文章节和小节；
3. 教材原有的“阅读与思考”“探究与发现”“图说数学史”“信息技术应用”等栏目；
4. 数学活动；
5. 小结；
6. 综合与实践。

教材明确编号的内部小节视为课程结构锚点，不允许为了 App 展示方便任意改名、重新编号或拆成伪教材小节。一个编号小节内部可以组织多个 step、example、checkpoint 和 practice；确需增加 App 课时，只能使用不冒充教材编号的教学标题，并保持原概念顺序和页码归属。

## 语言风格

优先采用教材式推进：

```text
问题 / 情境
→ 观察、思考或探究
→ 概念与法则归纳
→ 例题
→ 练习 / 检查
→ 小结
```

正文要求：

- 先提出需要解决的问题，再给结论，避免一上来堆定义；
- 定义、法则和术语使用中学教材习惯表达，不使用网络化、营销化、口语过度的表达；
- 不把“技巧”包装成脱离依据的口诀；涉及移项、去括号、符号规则时说明其等式性质或运算律依据；
- 例题步骤写清“为什么这样变形”，不只写计算结果；
- 练习解析与最终答案分开，解析按必要步骤展开；
- 数学史、阅读材料和综合实践保留其栏目性质，不改写成普通定义课；
- 课程可以比教材更直观，但不能比教材更随意。

## 可视化原则

可视化只在确实能降低理解成本时使用，重点包括：

- 正负方向与相反意义的量；
- 数轴、相反数、绝对值和大小比较；
- 有理数加减中的数轴运动；
- 符号规则与乘方过程；
- 方程两边相等的天平模型；
- 立体图形到平面信息的投影；
- 直线、射线、线段和角的结构关系。

课程只提交已注册 renderer 的数学/教学语义参数和显示文字。不得在课程中写 Canvas、像素、采样算法、类名、URL、文件路径、回调或任意可执行代码。

## App CI/CD 与课程内容的边界

本项目的 GitHub Actions 只服务 **App 自身**：Android/Kotlin 编译、单元测试、App 架构检查、APK/更新包构建和 App 发布。

课程包属于独立的内容工程，不进入 App CI/CD：

- `courses/**` 的内容变化不应触发 App CI/CD；
- App CI/CD 不判断某一本教材的目录、页码、知识点、答案或语言风格；
- App CI/CD 不负责课程包打包、上传或发布；
- 教材专属 validator 不得作为 GitHub Actions 的质量门禁。

课程审校由课程审校 Agent / 子代理、人工复核、本地 validator 或其他独立内容工程流程完成。工具可以复用 App 暴露的课程 contract / visualization contract，但内容是否正确由内容工程负责。

## 精校检查

每次修改至少检查：

- 章节、栏目、教材编号小节和课时顺序是否与教材一致；
- `references` 是否使用教材印刷页，且没有把 PDF 页码误当印刷页；
- 定义、法则、术语是否符合教材口径，例如本册使用“准确数”和“近似数”；
- 例题、checkpoint、practice 的答案是否重新计算过；
- 分数、负号、括号、乘方、度分秒和单位是否无歧义；
- 题目条件是否足够，答案是否唯一或明确列出全部可能；
- 是否出现“重新核对”“这里先这样”“待补”等编辑过程残留；
- 是否出现长段教材原文复制；
- 可视化是否服务当前概念，而不是为了装饰；
- 课程契约和 visualization schema 是否由审校工具验证通过。

`validate_pep_math_7_1_editorial.py` 负责锁定教材目录、关键内部小节、印刷页范围、前置课时完整性以及已经人工复核的确定性练习答案。它由 Agent/人工内容流程按需调用；修改这些内容时应先确认教材或重新计算，而不是通过放宽校验迁就课程数据。

## 完成标准

新 `pep-math-7-1` 只有在以下条件同时满足时才视为完成：

- 六章和所有教材特殊栏目按目录顺序覆盖；
- 教材明确编号的内部小节与名称保持一致；
- 印刷页 1～195 的教学内容均能由相应章节/栏目引用到；
- 所有例题、检查题和练习完成数学正确性复核；
- 不存在旧生成课程、旧分卷源码、旧临时标题或旧 scene 兼容；
- 不存在一次性迁移脚本或 one-shot workflow；
- authored course contract、教材结构和 visualization schema 已由 Agent/人工内容审校流程验证；
- 课程发布独立于 App CI/CD，不要求重新构建 App。
