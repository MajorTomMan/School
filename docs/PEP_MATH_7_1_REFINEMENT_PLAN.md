# 人教版数学七年级上册逐页精校基线

> 教材：义务教育教科书·数学七年级上册（2022 年课程标准修订版）  
> PDF 总页数：202 页  
> 本文件是 `pep-math-7-1` 的逐页精校验收基线。课程包只有在六章内容、知识点、题目和必要可视化全部通过本清单后，才能标记完成。

## 总体验收规则

- 每个课程页面必须记录原教材 `sourcePage`，不得以章节标题或自动生成页替代原页映射。
- 标题、正文、公式、例题、练习、探究、思考、阅读材料和小结必须保持原教材顺序。
- 正负号、绝对值符号、分数线、乘方上下标、角度符号、单位和区间端点必须逐项校验。
- 例题必须包含题干、必要步骤和最终结论；练习题必须做到一题一页，并有答案、解析和知识点关联。
- Canvas 只绘制几何图形；教学文字使用 Compose `Text`，兼容全局字号调整。
- 不为装饰而加图。只有具象模型、空间关系、运动过程、数量趋势或结构关系能明显降低理解成本时才增加可视化。
- 所有新场景继承对应学科可视化父类，并在数学模块显式注册；禁止在课程页面直接复制整套 Canvas 逻辑。

## 第一章 有理数（PDF 8-30）

### 1.1 正数和负数（PDF 9-13）

逐页检查：

- 现实中相反意义的量是否保留完整语境，不能只剩抽象定义。
- 正数、负数和 0 的关系是否表述准确；0 既不是正数也不是负数。
- 中国古代负数史料、记数方法和教材阅读材料不得遗漏或改写成不准确的历史结论。
- 温度、海拔、收支、增长率、质量偏差和零件公差的单位、基准及正负方向必须一致。

可视化：

- 温度：温度计和 0 ℃ 基准。
- 海拔：山脉、海平面和水下地形。
- 收支、增长率：带 0 基准的折线趋势。
- 质量偏差：标准质量天平和偏差位置。
- 允许偏差：标准件与当前件叠影、公差带及五种判定状态。

### 1.2.1 有理数的概念（PDF 14）

逐页检查：

- 正整数、0、负整数构成整数；正分数、负分数构成分数。
- 有限小数和无限循环小数作为分数表达时不得出现错误归类。
- 集合分类图不能造成“整数与分数重叠”或“0 属于正整数”的误解。

可视化：有理数分类树与集合包含关系，避免使用重叠不准确的韦恩图。

### 1.2.2 数轴（PDF 15-17）

逐页检查：

- 数轴三要素：原点、正方向、单位长度。
- 点与数的一一对应应限定在数轴上的点与实数；七年级阶段讲解不得提前引入不必要术语。
- 例题点位、刻度和单位长度必须与原图一致。

可视化：可缩放数轴、点位读取、拖动定位、单位长度变化与错误示范。

### 1.2.3 相反数（PDF 18-19）

逐页检查：

- 只有符号不同的两个数互为相反数；0 的相反数是 0。
- `-a` 表示 `a` 的相反数，不得直接解释成负数。
- 多重符号化简必须按“求相反数”逐层解释。

可视化：数轴关于原点对称的双点与距离线。

### 1.2.4 绝对值（PDF 20）

逐页检查：

- 绝对值的几何意义是点到原点的距离。
- 正数、0、负数的绝对值分情况表述完整。
- `|a|` 结果非负，不得把绝对值理解成“去掉负号”。

可视化：点到原点的双向距离、相反数绝对值相等。

### 1.2.5 有理数大小比较（PDF 21-27）

逐页检查：

- 数轴右边的数大于左边的数。
- 两个负数比较时，绝对值大的反而小。
- 比较步骤、符号和不等号方向必须逐题核对。

可视化：数轴点位排序、负数距离反向关系、温度排序。

### 第一章小结与复习（PDF 28-30）

- 建立知识结构：现实量 → 有理数 → 数轴 → 相反数/绝对值 → 大小比较。
- 综合题必须覆盖概念辨析、数轴定位、绝对值和大小比较。

## 第二章 有理数的运算（PDF 31-74）

### 2.1.1 有理数的加法（PDF 32-36）

逐页检查：

- 同号相加、异号相加、互为相反数、与 0 相加四类规则完整。
- 运算规则中的“绝对值较大的加数符号”不能省略。
- 加法交换律、结合律使用条件与步骤必须正确。

可视化：数轴连续移动；起点、方向、位移和终点独立标注。

### 2.1.2 有理数的减法（PDF 37-44）

逐页检查：

- 减去一个数等于加上这个数的相反数。
- 省略加号的代数和写法必须保持符号归属。
- 混合加减不得通过机械“移项”解释。

可视化：减法转化为加法的两阶段数轴动画与符号变换流程。

### 2.2.1 有理数的乘法（PDF 45-49）

逐页检查：

- 两数相乘符号规则与绝对值规则。
- 多个非零数相乘由负因数个数奇偶决定符号。
- 任意数与 0 相乘得 0。
- 交换律、结合律、分配律的使用不得漏括号。

可视化：符号状态机、负因数奇偶计数、面积/分配律结构。

### 2.2.2 有理数的除法（PDF 50-57）

逐页检查：

- 除以不等于 0 的数等于乘其倒数。
- 0 不能作除数。
- 分数、除法和倒数之间转换步骤完整。

可视化：乘法与除法互逆关系图、倒数配对。

### 2.3.1 乘方（PDF 58-60）

逐页检查：

- 底数、指数、幂的定义和读法。
- 负数乘方必须区分 `(-a)^n` 与 `-a^n`。
- 运算顺序：乘方 → 乘除 → 加减，同级从左到右。

可视化：重复因数展开、指数控制层数、括号差异对比。

### 2.3.2 科学记数法（PDF 61-63）

逐页检查：

- 标准形式 `a×10^n` 中 `1≤|a|<10`。
- 本册原教材范围及正整数指数要求保持一致。
- 原数位数与指数关系逐题校验。

可视化：小数点移动和位值尺。

### 2.3.3 近似数（PDF 63-65）

逐页检查：

- 精确数与近似数区分。
- 精确到哪一位与有效数字不得混用。
- 四舍五入后的末尾 0 在表达精确度时不能随意删除。

可视化：数轴舍入区间、目标数位放大镜。

### 第二章小结与复习（PDF 66-74）

- 混合运算题逐行校验括号、乘方和符号。
- 综合情境题必须保留单位、实际意义和结果解释。

## 第三章 代数式（PDF 75-94）

### 3.1 列代数式表示数量关系（PDF 76-85）

逐页检查：

- 字母表示数、数量关系和运算顺序。
- 乘号省略、数字因数写在字母前、带分数化假分数等书写规则。
- 单位名称含加减关系时需要括号。
- 同一情境不同表达式的等价性不得误判。

可视化：数量关系节点图、输入量到代数式的映射流程、几何量动态标注。

### 3.2 代数式的值（PDF 86-91）

逐页检查：

- 代入时使用括号，尤其是负数和分数。
- 代入后按有理数运算顺序计算。
- 同一代数式在不同取值下的变化趋势。

可视化：参数滑块、代入槽位、表格与折线趋势；不得把离散示例误画成连续函数结论。

### 第三章小结与复习（PDF 92-94）

- 检查语言 → 数量关系 → 代数式 → 代入求值的完整链路。

## 第四章 整式的加减（PDF 95-116）

### 4.1 整式（PDF 96-101）

逐页检查：

- 单项式的系数、次数；单独字母和常数的特殊情况。
- 多项式的项、常数项、次数。
- 分母含字母的式子不得归为整式。

可视化：单项式结构拆解器、多项式项的颜色分组与次数标尺。

### 4.2 整式的加法与减法（PDF 102-113）

逐页检查：

- 同类项必须同时满足字母相同且相同字母指数相同。
- 合并同类项只合并系数，字母及指数不变。
- 去括号与括号前符号规则。
- 整式加减先去括号，再合并同类项。

可视化：项卡片仅作为数学对象边界使用；同类项匹配、括号展开树和系数合并动画。

### 第四章小结与复习（PDF 114-116）

- 每道化简题必须逐项检查漏项、变号和次数。

## 第五章 一元一次方程（PDF 117-155）

### 5.1.1 从算式到方程（PDF 118-121）

逐页检查：

- 方程必须是含未知数的等式。
- 方程的解与解方程的区别。
- 建模步骤：设未知数、找等量关系、列方程。

可视化：算术逆推与方程模型对比、等量关系图。

### 5.1.2 等式的性质（PDF 122-126）

逐页检查：

- 等式两边加或减同一个数/式，等式仍成立。
- 两边乘同一个数或除以同一个非零数，等式仍成立。
- 除数非零条件不得遗漏。

可视化：天平模型，操作必须同步作用于左右两边。

### 5.2 解一元一次方程（PDF 127-139）

逐页检查：

- 合并同类项、移项、去括号、去分母、系数化为 1 的步骤与依据。
- 移项必须变号；不得把“移项”讲成无依据的跨越等号。
- 去分母时方程每一项都乘最小公倍数。
- 解后检验应至少在典型题中展示。

可视化：等式变形时间线、天平同步操作、步骤依赖图。

### 5.3 实际问题与一元一次方程（PDF 140-151）

逐页检查：

- 配套、工程、行程、销售、积分等问题的量与单位。
- 等量关系必须可追溯到题意，不能只给模板。
- 结果需要结合实际意义判断合理性。

可视化：线段图、行程时间轴、工程进度条、价格构成图和方案比较表。

### 第五章小结与复习（PDF 152-155）

- 建模、求解、检验、作答四步完整。

## 第六章 几何图形初步（PDF 156-202）

### 6.1.1 立体图形与平面图形（PDF 158-161）

逐页检查：

- 常见柱体、锥体、球及平面图形名称。
- 从不同方向看立体图形所得平面图形。
- 展开图与围成立体图形的对应关系。

可视化：可旋转的简化三维投影、三视图联动、展开与折叠步骤。若 Android Canvas 无可靠 3D 交互，使用确定性的轴测图而非伪 3D 装饰。

### 6.1.2 点、线、面、体（PDF 162-168）

逐页检查：

- 点动成线、线动成面、面动成体作为运动直观，不得替代严格概念。
- 平面与曲面、表面交线和顶点关系。

可视化：生成过程动画、几何元素层级图。

### 6.2.1 直线、射线、线段（PDF 169-170）

逐页检查：

- 三者端点个数、延伸方向和表示方法。
- 两点确定一条直线。
- 直线表示的字母顺序与小写字母写法。

可视化：端点与延伸方向切换、两点确定直线实验。

### 6.2.2 线段的比较与运算（PDF 171-176）

逐页检查：

- 度量法与叠合法。
- 线段和差、线段中点。
- 两点之间线段最短。

可视化：可拖动线段比较、中点约束、折线路径与直线路径对比。

### 6.3.1 角的概念（PDF 177-179）

逐页检查：

- 角的静态定义与旋转定义。
- 角的四种表示方法及顶点字母位置。
- 度、分、秒换算。

可视化：射线旋转、角弧、量角器刻度和单位换算。

### 6.3.2 角的比较与运算（PDF 180-182）

逐页检查：

- 度量法与叠合法。
- 角的和差、角平分线。
- 度分秒运算中的进位和借位。

可视化：角叠合、角平分线动态约束、度分秒位值器。

### 6.3.3 余角和补角（PDF 183-190）

逐页检查：

- 和为 90° 的两个角互余，和为 180° 的两个角互补。
- 同角或等角的余角相等；补角相等。
- 方位角读法、起始方向和旋转方向。

可视化：直角/平角拼合、余角补角联动、方位角罗盘。

### 第六章小结与复习（PDF 191-202）

- 几何表示方法、作图步骤和单位必须逐题检查。
- 作图题不能只给文字答案，应提供步骤图或可回放绘制过程。

## 课程包结构验收

`course.json`：

- 六章顺序与本文件一致。
- 每个 section 的页面顺序严格按教材。
- 每页必须包含有效 `sourcePage`。
- 同一教材页拆分成多个学习页时使用稳定后缀，并保留相同来源页。
- scene 的 template/key 必须在 Android 注册表中存在。

`knowledge-points.json`：

- 每个教学页至少关联一个明确知识点。
- 知识点必须拥有章节、前置关系、掌握目标和可复习标识。
- 不得以整个章节标题代替细粒度知识点。

`assessments.json`：

- 每道题具有唯一稳定 ID、题干、答案、解析、知识点和难度。
- 选择题答案必须属于选项；填空题答案格式与本地判题归一化规则一致。
- 负号、分数、单位和角度符号必须覆盖常见等价输入。
- 每个核心知识点至少有基础辨析、标准计算和综合应用题。
